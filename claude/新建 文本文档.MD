## 🎯 跳过登录的核心原理

Claude Code 启动时会检查本地的登录状态配置文件。通过手动创建这些文件，可以“欺骗”程序认为你已经完成登录，从而跳过验证。

> ⚠️ **重要说明**：此方法仅跳过本地登录校验，你仍需配置自己的 API 密钥或本地模型服务才能正常使用 Claude Code 的功能。

## 📝 详细操作步骤

### 第一步：完全关闭 Claude Code

打开任务管理器（`Ctrl + Shift + Esc`），找到所有 `Claude Code` 相关进程，右键点击“结束任务”，确保程序完全退出。

### 第二步：清理旧残留（可选但推荐）

如果之前尝试过登录或运行失败，建议先清理：

- 打开文件管理器，进入 `C:\Users\你的用户名\`
- 删除 `.claude` 文件夹（如果存在）
- 删除 `.claude.json` 文件（如果存在）

> 💡 **提示**：`.claude` 文件夹可能是隐藏的。在文件管理器顶部点击“查看” → 勾选“隐藏的项目”即可显示。

### 第三步：创建第一个核心文件 `.claude.json`

1. 进入用户目录：`C:\Users\你的用户名\`

2. 右键 → 新建 → 文本文档

3. 将文件命名为 `.claude.json`（注意：前面有英文句号“.”，后缀必须是 `.json`）

   > 如果系统提示“必须输入文件名”，可以先命名为 `claude.json`，保存后右键重命名，在前面加上 `.` 即可。

4. 用记事本打开，粘贴以下内容：

   json

   ```
   {
     "hasCompletedOnboarding": true,
     "primaryApiKey": "test"
   }
   ```

   

5. 保存并关闭文件

> **作用说明**：`hasCompletedOnboarding: true` 告诉程序已完成首次引导，`primaryApiKey` 伪造一个 API Key 来绕过密钥校验。

### 第四步：创建第二个核心文件 `.claude/settings.json`

1. 在用户目录下 `C:\Users\你的用户名\` 新建一个文件夹，命名为 `.claude`（前面有英文句号）

2. 进入该文件夹，新建文本文档，命名为 `settings.json`

3. 用记事本打开，粘贴以下内容：

   json

   ```
   {
     "env": {
       "CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC": "1"
     },
     "permissions": {
       "defaultMode": "bypassPermissions"
     }
   }
   ```

   

4. 保存并关闭文件

> **作用说明**：
>
> - `CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC: "1"` 禁用非必要的网络请求（包括登录校验）
> - `bypassPermissions` 跳过权限确认弹窗，让使用更流畅

### 第五步：验证破解效果

重新打开 Claude Code（在终端输入 `claude` 并回车），正常情况下：

- ✅ 不再弹出登录窗口
- ✅ 底部显示 `bypass permissions on`
- ✅ 直接出现 `>` 提示符

如果依然弹出登录窗口，请检查：

1. 配置文件路径是否正确（必须在用户目录，不是安装目录）
2. 文件命名是否正确（`.claude.json` 有句号，`settings.json` 无句号）
3. Claude Code 进程是否完全关闭后重启

## 🔧 进阶：配置 API 密钥或本地模型

跳过登录后，你还需要配置实际可用的 API 才能正常对话。有以下几种方式：

### 方式一：使用第三方 API（如 DeepSeek、Kimi）

在 `C:\Users\你的用户名\.claude\settings.json` 中添加环境变量：

json

```
{
  "env": {
    "ANTHROPIC_BASE_URL": "https://api.deepseek.com/v1",
    "ANTHROPIC_AUTH_TOKEN": "你的API密钥",
    "ANTHROPIC_MODEL": "deepseek-chat",
    "CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC": "1"
  },
  "permissions": {
    "defaultMode": "bypassPermissions"
  }
}
```



### 方式二：使用本地模型（Ollama 等）

如果本地部署了 Ollama 或其他本地模型：

json

```
{
  "env": {
    "ANTHROPIC_BASE_URL": "http://localhost:11434/v1",
    "ANTHROPIC_AUTH_TOKEN": "任意占位符",
    "ANTHROPIC_MODEL": "你的本地模型名称",
    "CLAUDE_CODE_ATTRIBUTION_HEADER": "0"
  },
  "permissions": {
    "defaultMode": "bypassPermissions"
  }
}
```



## 🛠️ 备选方案：使用 CCGO 启动器

如果你觉得手动创建配置文件比较麻烦，还可以使用社区开发的 **CCGO** 启动器，它可以一键完成配置：

bash

```
# 1. 确保已安装官方 Claude Code
npm install -g @anthropic-ai/claude-code

# 2. 安装 CCGO（不要先运行 claude 命令）
npm install -g ccgo

# 3. 初始化配置（自动跳过登录）
ccgo init

# 4. 配置 API（可选）
ccgo config   # 会显示配置文件位置

# 5. 启动
ccgo
```



CCGO 的配置文件位置：

- Windows: `%APPDATA%\cc-code-status\config.json`

## ❓ 常见问题

| 问题                                           | 解决方法                                                     |
| :--------------------------------------------- | :----------------------------------------------------------- |
| 启动后仍提示登录                               | 检查配置文件是否在正确的用户目录，文件名是否正确，进程是否完全关闭 |
| 找不到 `.claude` 文件夹                        | 需要在文件管理器中勾选“显示隐藏的项目”                       |
| 无法命名为 `.claude.json`                      | 先命名为 `claude.json`，保存后再重命名加上前面的点           |
| 提示 "Unable to connect to Anthropic services" | 检查 `ANTHROPIC_BASE_URL` 和 `ANTHROPIC_AUTH_TOKEN` 配置是否正确 |
