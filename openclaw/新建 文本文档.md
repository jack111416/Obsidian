# 升级方案一（优先，原地升级、保留全部配置，不走安装脚本）

### 1、停服务 + 清缓存

bash



运行







```
openclaw daemon stop
openclaw gateway stop
npm cache clean --force
```

### 2、安装命令（关键：`--ignore-scripts` 跳过 gyp 编译，屏蔽 tree-sitter 报错，Termux 专用）

bash



运行







```
export CI=1
npm install -g openclaw@latest --ignore-scripts --no-optional
```

> `CI=1`关闭交互式编译弹窗，`--ignore-scripts`直接跳过所有原生模块构建，彻底规避`android_ndk_path`缺失报错

### 3、修复环境 + 重启

bash



运行



#  `gateway start` 

这里有三种解决方案，你可以根据自己的情况选择：

### ✅ 方案一：前台运行（最简单，适合测试）

运行这个命令，网关会直接在前台启动，输出所有实时日志，方便排查问题。唯一的缺点是关掉 Termux 窗口网关就会停止。

bash

```
openclaw gateway --port 18789 --verbose
```



### 🚀 方案二：后台运行（推荐长期运行）

这个方案更适合你希望网关能在后台长期稳定运行。它有两种实现方式，都很流行：

#### **1. 使用 `tmux` 终端复用器（社区主流方案）**

这是社区最推荐的方案。它会创建一个独立的会话，让网关在后台安静地跑，就算关了 Termux，它也会继续运行。

- **第一步：安装 tmux**

  bash

  ```
  pkg install tmux
  ```

  

- **第二步：创建并启动会话**

  bash

  ```
  tmux new -s openclaw
  ```

  

- **第三步：在会话中启动网关**
  进入 tmux 会话后，运行启动命令：

  bash

  ```
  openclaw gateway --port 18789 --verbose
  ```

  

- **管理方法：**

  - **临时切出：** 按 `Ctrl+B` 再按 `D`，会话会保存到后台。
  - **重新连回：** `tmux attach -t openclaw`
  - **强制结束：** `tmux kill-session -t openclaw`

#### **2. 使用 PM2 进程守护**

如果你更熟悉 Node.js 生态，也可以使用 `pm2` 来管理。

- **安装并启动：**

  bash

  ```
  npm install -g pm2
  pm2 start openclaw --name "openclaw-gateway" -- gateway --port 18789 --verbose
  pm2 save
  pm2 startup
  ```
