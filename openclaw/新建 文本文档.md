## 安装流程

共 7 步，每步自动计时并输出耗时：

```
📦  步骤 1/7  安装系统依赖
⚡  步骤 2/7  安装 OpenClaw
🔧  步骤 3/7  Android 兼容修复
🌐  步骤 4/7  检测局域网 IP
📄  步骤 5/7  生成配置文件
🤖  步骤 6/7  配置 AI 模型
🚀  步骤 7/7  生成启动脚本
```

步骤 1：安装系统依赖

自动执行 `pkg update && pkg upgrade`，并安装以下包：

- `nodejs-lts` — Node.js 运行环境
- `curl` — 网络工具
- `git` — 版本管理
- `iproute2` + `net-tools` — 网络检测

安装完成后显示 Node.js 版本号。

步骤 2：安装 OpenClaw

通过 npm 全局安装最新版：

```
npm install -g openclaw@latest --ignore-scripts
```

- 若已安装则自动跳过
- 安装过程显示旋转动画，提示"请耐心等候"
- 安装完成后显示 OpenClaw 版本号

步骤 3：Android 兼容修复

OpenClaw 依赖的 `koffi` 原生模块在 Android ARM64 上无法编译。脚本自动注入 Proxy 桩代码，将 koffi 的所有方法调用静默拦截，避免因找不到原生模块而崩溃。

步骤 4：检测局域网 IP

自动扫描设备网卡获取局域网 IP 地址：

1. 优先使用 `ifconfig` 过滤 `inet` 地址
2. 备用 `ip route get 1.1.1.1` 取默认路由 IP
3. 都失败则提示用户手动输入

检测到后显示接口名（如 `wlan0`）和 IP 地址。

步骤 5：生成配置文件

在 `~/.openclaw/openclaw.json` 生成网关配置文件：

|配置项|默认值|说明|
|---|---|---|
|`gateway.port`|`18789`|网关端口，可通过 `GATEWAY_PORT` 环境变量修改|
|`gateway.bind`|`"lan"`|允许局域网访问|
|`auth.token`|随机 40 位 hex|访问令牌|
|`controlUi.enabled`|`true`|启用 Web 控制面板|
|`nodes.denyCommands`|相机/屏幕/短信等|限制敏感操作|
|`tailscale.mode`|`"off"`|不启用 Tailscale|

- 已有旧配置时自动备份（`.bak.时间戳`）
- Token 通过 `/dev/urandom` 随机生成

步骤 6：配置 AI 模型

支持 5 大 AI 提供商：

|#|提供商|特点|
|---|---|---|
|1|**DeepSeek**|性价比高，原生推理，推荐|
|2|**OpenAI**|GPT-4o 系列|
|3|**Anthropic**|Claude Sonnet 4|
|4|**Google**|Gemini 2.5 Flash|
|5|**自定义**|任意 OpenAI 兼容接口|

**DeepSeek 预置模型：**

|模型 ID|上下文窗口|最大输出|推理|
|---|---|---|---|
|`deepseek-chat`|131K|8K|—|
|`deepseek-reasoner` (R1)|131K|65K|✅|
|`deepseek-v4-flash`|**1M**|384K|✅|
|`deepseek-v4-pro`|**1M**|384K|✅|

交互式菜单引导用户完成：选择提供商 → 选择模型 → 输入 API Key。

**非交互模式（环境变量）：**

```
AI_PROVIDER=deepseek AI_MODEL=deepseek/deepseek-v4-flash \
  DEEPSEEK_KEY="sk-your-key" bash install-openclaw.sh
```

步骤 7：生成启动脚本

生成 `~/start-openclaw.sh`，功能：

- 自动关闭旧进程
- 启动 Gateway + Dashboard
- 列出所有网卡访问地址
- `Ctrl+C`

```
# 启动
~/start-openclaw.sh
```

环境变量

|变量|默认值|说明|
|---|---|---|
|`GATEWAY_PORT`|`18789`|网关端口|
|`AI_PROVIDER`|交互选择|强制指定提供商|
|`AI_MODEL`|交互选择|强制指定模型 ID|
|`DEEPSEEK_KEY`|交互输入|API Key|

---

注意事项

1. **必须使用 Termux 运行**，其他环境会直接退出
2. npm 安装 OpenClaw 是**最耗时的一步**（2-5 分钟），请勿中断
3. 配置文件中的 `allowInsecureAuth` / `dangerouslyDisableDeviceAuth` 已开启——这是为了方便手机本地使用，**请勿将配置暴露到公网**
4. 安装完成后执行 `~/start-openclaw.sh` 即可启动

常见问题

**Q: 安装到一半网络断了怎么办？**  
A: 重新运行脚本即可，已完成的步骤自动跳过。

**Q: 忘记了 Token？**  
A: 查看 `~/.openclaw/openclaw.json` 中的 `auth.token`。

**Q: 启动报 "koffi" 相关错误？**  
A: 步骤 3 的桩代码未生效，重新运行安装脚本。

**Q: 局域网访问不了？**  
A: 确认手机和电脑在同一 WiFi 下；VPN 可能影响局域网访问。

#  `gateway start` 

这里有三种解决方案，你可以根据自己的情况选择：

### ✅ 方案一：前台运行（最简单，适合测试）

运行这个命令，网关会直接在前台启动，输出所有实时日志，方便排查问题。唯一的缺点是关掉 Termux 窗口网关就会停止。

bash

```
openclaw gateway --port 18789 --verbose
```



### 🚀 方案二：后台运行（推荐长期运行）

这个方案更适合你希望网关能在后台长期稳定运行。它有两种实现方式，都很流行：

#### **1. 使用 `tmux` 终端复用器（社区主流方案）**

这是社区最推荐的方案。它会创建一个独立的会话，让网关在后台安静地跑，就算关了 Termux，它也会继续运行。

- **第一步：安装 tmux**

  bash

  ```
  pkg install tmux
  ```

  

- **第二步：创建并启动会话**

  bash

  ```
  tmux new -s openclaw
  ```

  

- **第三步：在会话中启动网关**
  进入 tmux 会话后，运行启动命令：

  bash

  ```
  openclaw gateway --port 18789 --verbose
  ```

  

- **管理方法：**

  - **临时切出：** 按 `Ctrl+B` 再按 `D`，会话会保存到后台。
  - **重新连回：** `tmux attach -t openclaw`
  - **强制结束：** `tmux kill-session -t openclaw`

#### **2. 使用 PM2 进程守护**

如果你更熟悉 Node.js 生态，也可以使用 `pm2` 来管理。

- **安装并启动：**

  bash

  ```
  npm install -g pm2
  pm2 start openclaw --name "openclaw-gateway" -- gateway --port 18789 --verbose
  pm2 save
  pm2 startup
  ```
