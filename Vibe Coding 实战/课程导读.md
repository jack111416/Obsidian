

## 这门课是做什么的？

这不是一门"教你几个提示词技巧"的课，而是一门完整的 **AI Coding 方法课**。  
你会学到：如何把 AI 从"代码补全工具"变成"可协作、可约束、可交付"的研发搭档。

最终目标是：

- 你能稳定做出可运行功能，而不是偶尔生成一段代码；
- 你能管理复杂需求，而不是只会写单点页面；
- 你能构建自己的 AI 开发流程，而不是依赖临场发挥。

---

## 你会在这门课学到什么？

学完后你将具备这几类核心能力：

1. **AI协作基本功**：知道如何提需求、控上下文、稳输出质量。
2. **规则化开发能力**：用 `System Prompt` 和 `Rules` 固化你的编码习惯。
3. **工程化交付能力**：从需求到实现到验收形成闭环，不跑偏。
4. **工具扩展能力**：通过 MCP 连接数据库、文档、仓库等外部能力。
5. **Agent实战能力**：让 AI 从"被动建议"升级为"主动执行任务"。
6. **多 Agent 协同能力**：处理更大规模任务，提升并行效率与可控性。

## 课程章节导览（第一章到第十一章）

### 第一章：Vibe Coding 入门

你会理解 Vibe Coding 的核心理念，熟悉 CloudStudio + CodeBuddy 环境：  
在不手写业务代码的前提下做出一个可预览的登录页面，建立正确的人机分工认知。

### 第二章：System Prompt 与 Rules

你会学会用规则稳定 AI 的输出风格：  
在 CodeBuddy 中建立一套个性化编码规范，让生成的代码更贴近你的习惯。

### 第三章：上下文工程

你会掌握"给 AI 喂什么信息、喂多少信息"：  
避免上下文过多/过少，学会精准注入文件、目录、文档与代码片段。

### 第四章：Inline Edit 与高效迭代

你会进入真正高频开发状态：  
局部改、快速看 diff、即时修正，减少上下文切换，保持心流。

### 第五章：Spec-driven（规约驱动）开发

你会掌握 Speckit 的核心概念与标准工作流：  
从 constitution → specify → clarify → plan → tasks → analyze → implement，能够独立完成一次从规约到实现的完整流程。

### 第六章：SpeckitList 与长任务治理

你会把复杂功能拆成可执行的小任务：  
用 SpeckitList 管理进度，让 AI 按顺序推进；当结果跑偏时，优先回到 Speckit 做修正。

### 第七章：MCP 能力扩展

你会了解 MCP 的基本概念与接入方式：  
把外部数据源（例如数据库结构）接到 AI 的上下文里，让生成的代码更贴近真实系统。

### 第八章：Agent Skills

你会理解 Agent Skills 的核心价值与触发机制：  
掌握 SKILL.md 的基础结构，并能在 CodeBuddy 中完成一次可复现的 Skill 配置与调用。

### 第九章：CodeBuddy Agent SDK 实践指南

你会理解并构建可执行 Agent：  
随着大语言模型能力的提升，让 AI 从"对话问答"升级为能够自主完成任务的 Agent，进入自动化开发阶段。

### 第十章：CLI 多 Agent 协作实战

你会掌握在 CodeBuddy CLI 场景下组织多 Agent 协作的完整方法：  
能够把一个中等复杂需求拆分为"前端 Agent / 后端 Agent / 测试 Agent / 审查 Agent"并行执行，提升交付效率并保留质量控制。

### 第十一章：CI/CD 自动化流程

你会掌握 CodeBuddy CLI 的非交互模式（`-p` 管道模式）：  
将 AI 能力嵌入 CI/CD 流水线，实现自动代码审查、自动测试生成，并理解企业级部署的最佳实践。

---

## 建议你怎么学

- 每章都做最小实操，不只看概念。
- 每两章做一次"复盘+固化规则"。
- 从你当前真实项目中抽 1 个需求全流程演练。

这样学完这门课，你得到的不只是知识点，而是一套可持续复用的 AI Coding 工作体系。
