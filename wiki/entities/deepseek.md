# DeepSeek

> 中国 AI 公司，以高性价比推理模型著称。

## 关键模型

- **DeepSeek-V3**：大规模 MoE 模型
- **DeepSeek-R1**：推理增强模型，擅长数学和代码任务

## 定位

- 追求"高效推理"
- API 价格低于 OpenAI 同类模型数倍
- 在代码生成、数学推理等基准上表现优异
