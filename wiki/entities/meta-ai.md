# Meta AI

> Meta（原 Facebook）旗下 AI 研究部门，以开源模型推动 LLM 生态发展。

## 关键贡献

### LLaMA 系列
- LLaMA 1（2023）：首个开源高性能 LLM，证明"数据质量 > 数据量"
- LLaMA 2（2023）：商用许可，7B-70B 参数
- LLaMA 3/4（2024-2025）：持续改进，多模态扩展

### 开源生态
- 推动"AI for everyone"开源运动
- 与 Hugging Face 深度合作

## configuration
- 专注降低 LLM 部署门槛
- 支持社区微调和本地部署
