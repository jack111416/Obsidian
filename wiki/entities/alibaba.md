# 阿里巴巴（通义千问）

> 中国科技巨头，旗下 AI 模型品牌为"通义千问"（Qwen）。

## 关键模型

- **Qwen**（通义千问）：支持多语言、长上下文、代码、数学
- 系列覆盖 0.5B 到 110B+ 参数
- 开源模型在 Hugging Face 上广泛使用

## 特点

- 强调中文场景优化
- 开源生态活跃
- 企业级 API 服务
