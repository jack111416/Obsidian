# GEO搜索优化·AI获客系统 - 项目说明文档

> 版本：v1.0 | 更新日期：2026-05-31

## 一、产品概述

**一句话定义**：
**一套基于OpenClaw多Agent架构的抖音自动化获客系统，通过AI批量生产GEO优化内容并自动分发，帮助企业占据AI搜索引擎推荐位。**

**解决的核心问题**：
AI搜索时代（豆包、文心一言、DeepSeek等），63%的用户已转向AI获取信息，传统SEO失效。本系统让企业内容被AI主动抓取、优先推荐，实现持续精准获客。

## 二、目标用户

| 用户类型           | 核心痛点                   | 使用场景                         |
| :----------------- | :------------------------- | :------------------------------- |
| **企业主/创业者**  | 客户被AI推荐给同行         | 每周查看数据、审核内容、跟进线索 |
| **市场运营负责人** | 内容生产效率低、多账号难管 | 配置选题、审核脚本、监控竞品     |
| **数字营销服务商** | 需规模化服务客户           | 部署系统批量获客，收取服务费     |
| **AI自动化爱好者** | 想用AI实现被动收入         | 学习架构、二次开发、垂直领域复制 |

### 4.2 各页面功能说明

#### 页面1：仪表盘（Dashboard）

| 功能区域   | 展示内容                           | 操作         |
| :--------- | :--------------------------------- | :----------- |
| 核心指标   | 总视频数、总播放量、私信数、线索数 | 点击进入详情 |
| 趋势图     | 近7日播放量/私信量折线图           | 切换日期范围 |
| 待处理线索 | 未跟进的高意向客户                 | 点击立即跟进 |
| 任务队列   | 今日待发布/进行中任务              | 查看全部     |

#### 页面2：内容工厂（Content）

| 子页面   | 功能           | 关键操作             |
| :------- | :------------- | :------------------- |
| 选题库   | 管理选题列表   | 新增选题、AI推荐     |
| 脚本生成 | AI生成脚本     | 选择模板、生成、编辑 |
| 视频合成 | 脚本转视频     | 选音色、合成、预览   |
| 素材管理 | 上传/管理素材  | 上传、打标签、搜索   |
| 成品库   | 已生成视频列表 | 预览、下载、发布     |

#### 页面3：账号中心（Accounts）

| 子页面   | 功能           | 关键操作           |
| :------- | :------------- | :----------------- |
| 设备列表 | 所有已连接设备 | 查看状态、断开     |
| 账号绑定 | 管理抖音账号   | 添加、编辑、删除   |
| IP配置   | 绑定独立代理IP | 添加IP、测试、绑定 |
| 健康度   | 账号权重评分   | 查看详情、优化建议 |

#### 页面4：发布任务（Publish）

| 子页面   | 功能                   | 关键操作             |
| :------- | :--------------------- | :------------------- |
| 立即发布 | 选择视频和目标账号     | 选视频、选账号、发布 |
| 定时任务 | 设置未来发布时间       | 新增、编辑、删除     |
| 批量群发 | 一视频多发或多视频批量 | 选列表、设间隔、执行 |
| 发布记录 | 历史发布任务           | 查看状态、重试       |

#### 页面5：互动管理（Interaction）

| 子页面   | 功能             | 关键操作             |
| :------- | :--------------- | :------------------- |
| 私信管理 | 所有账号私信汇总 | 查看、回复、标记线索 |
| 评论管理 | 所有评论汇总     | 查看、回复、删除     |
| 回复规则 | 关键词+话术配置  | 新增规则、测试       |
| 线索池   | 高意向客户汇总   | 查看详情、导出       |

#### 页面6：数据报表（Analytics）

| 子页面   | 功能                     | 关键操作             |
| :------- | :----------------------- | :------------------- |
| 内容分析 | 每条视频的完播率、互动率 | 排序筛选、对比       |
| 账号分析 | 各账号粉丝、播放趋势     | 切换账号、时间范围   |
| 竞品监控 | 竞品账号动态             | 添加竞品、查看对比   |
| 导出中心 | 导出各类报表             | 选类型、选时间、导出 |

#### 页面7：系统设置（Settings）

| 子页面   | 功能             | 关键操作           |
| :------- | :--------------- | :----------------- |
| API配置  | 配置阿里百炼密钥 | 填写Key、测试连接  |
| 模型选择 | 选择AI模型       | 下拉选择、保存     |
| 代理设置 | 配置网络代理     | 填写地址、测试     |
| 成员管理 | 团队权限管理     | 邀请成员、设置角色 |
