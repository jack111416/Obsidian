## 📋 下一步操作清单

### **立即执行 - Phase 1 Task 1.1**

1. **Step 1: 手机端发起配对（关键！）**

   1. **打开 OpenClaw Android App**
   2. 在App主界面，点击 **"配对新设备"** 或 **"添加设备"** 按钮
   3. App会显示：
      - 一个**二维码**
      - 一个**6位数字配对码**（如 `ABCD-1234`）
   4. **记下这个配对码**（或准备好扫码）

   ------

   ### **Step 2: 电脑端确认配对**

   手机上显示配对码后，**电脑会收到通知**：

   复制

   ```bash
   # 可能弹窗或在终端显示:
   New pairing request from Android Device
   Device ID: android-xxxxxxxxxxxx
   Pairing Code: ABCD-1234
   Accept? (y/n):
   ```

   这时输入 `y` 确认配对。

   **或者**，你也可以在电脑上先运行：

   复制

   ```bash
   openclaw nodes pending
   ```

   然后**快速**在手机上发起配对，这样pending命令会显示等待的请求。

2. 验证配对成功：

   复制

   ```bash
   openclaw nodes status
   ```

   应看到设备状态为 `online`
